# Plan 4.2: Dual-Format Export Engine (ReportLab PDF & OpenPyXL)

## Objective
Implement high-fidelity in-memory export generators for monthly financial intelligence reports: an executive PDF with AI health scoring via ReportLab, and a structured Excel workbook (.xlsx) via OpenPyXL.

## Context
- .gsd/SPEC.md
- .gsd/DECISIONS.md
- finance_app/app/reports/routes.py
- finance_app/app/models/financial_profile.py

## Tasks

<task type="auto">
  <name>Build ReportLab PDF Financial Statement Generator</name>
  <files>finance_app/requirements.txt, finance_app/app/services/pdf_export.py</files>
  <action>
    1. Add `reportlab>=4.1.0` to requirements.txt.
    2. Create `app/services/pdf_export.py` with `generate_monthly_pdf(user_id, month, year)`.
    3. Construct a 2-section report:
       - Section 1: Executive AI Summary (composite score, monthly savings rate, active overspending alerts, top Groq advice).
       - Section 2: Tabular Ledger (date, description, category, account, type, amount in PKR).
    4. Stream generated bytes via `io.BytesIO` without writing temp files to disk.
  </action>
  <verify>python -c "from app.services.pdf_export import generate_monthly_pdf; print(callable(generate_monthly_pdf))"</verify>

</task>
