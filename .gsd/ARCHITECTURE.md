## Components

### 1. Web Endpoints & Blueprints (`finance_app/app/`)
- **`app/auth/`**: Authentication (login, register, logout, password reset, OAuth).
- **`app/dashboard/`**: Overview dashboard with summary cards, charts, and AI health banner.
- **`app/accounts/`**: Bank and wallet account lifecycle (CRUD, balances).
- **`app/transactions/`**: Income/expense recording, CSV import/export, filtering.
- **`app/budgets/`**: Monthly spending limits and progress tracking.
- **`app/savings/`**: Target goals, milestone contributions, progress bars.
- **`app/ai/`**: AI Command Center (`/ai/advisor`), profile editor (`/ai/profile`), AJAX chat (`/ai/chat`), API key configuration modal (`/ai/api-key/*`).

### 2. Services (`finance_app/app/services/`)
- **`groq_middleware.py`**: Multi-tiered API key resolution (Profile -> Env -> Offline), live connection check, prompt context builder, model routing (`openai/gpt-oss-120b`, `qwen/qwen3.8-27b`).
- **`recommender.py`**: Pakistani localized product substitutions (Careem -> InDrive, KFC -> local food, Panadol -> Paracetamol).
- **`spending_predictor.py`**: Historical transaction aggregation and regression spending forecast.
- **`ai_alerts.py`**: Automated detection of anomalous category spend vs income.
- **`auto_categorizer.py`**: Heuristic keyword classification for Pakistani merchant transactions.

### 3. Models (`finance_app/app/models/`)
- **`User`**: Account owner, authentication credentials, relationship mappings.
- **`FinancialProfile`**: Monthly income (PKR), housing, family size, Kaggle-based financial advice score (0-100), custom `groq_api_key`, `preferred_model`.
- **`Transaction`**: Amount, date, type (income/expense), category, account reference.
- **`Budget` & `SavingsGoal`**: Financial goals and category thresholds.
- **`AiChatMessage`**: Multi-turn conversation persistence with token tracking.

## Data Flow

1. User logs transaction -> `Transaction` stored in SQLite.
2. Analytics trigger -> `ai_alerts` inspects monthly totals against `FinancialProfile` income.
3. Advisor route accessed (`/ai/advisor`) -> compiles live health score, ML spending forecasts, overspending alerts, and alternatives.
4. User asks AI a question -> `GroqMiddleware` resolves active API key -> assembles financial context system prompt -> invokes Groq API -> streams response -> saves to `AiChatMessage`.
