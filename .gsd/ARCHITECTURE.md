### 2. Services (`finance_app/app/services/`)
- **`groq_middleware.py`**: Multi-tiered API key resolution (Profile -> Env -> Offline), live connection check, prompt context builder, model routing (`openai/gpt-oss-120b`, `qwen/qwen3.8-27b`).
- **`recommender.py`**: Pakistani localized product substitutions (Careem -> InDrive, KFC -> local food, Panadol -> Paracetamol).
- **`spending_predictor.py`**: Historical transaction aggregation and regression spending forecast via scikit-learn.
- **`ai_alerts.py`**: Automated detection of anomalous category spend vs income.
- **`auto_categorizer.py`**: Heuristic keyword classification for Pakistani merchant transactions.
- **`subscription_leakage.py`**: Detection of recurring charges, zombie subscriptions, and unused bill commitments.
- **`ledger_stream.py`**: Real-time WebSocket broadcasting of transaction events (`/ws/ledger`).
- **`pdf_export.py`**: High-fidelity PDF report compilation using ReportLab.
- **`excel_export.py`**: Detailed financial workbook exports via OpenPyXL.
- **`crypto.py` & `credential_manager.py`**: Secure AES/Fernet encryption for user API keys and credentials.

- **`Transaction`**: Amount, date, type (income/expense), category, account reference.
- **`Account`**: Bank/wallet institutions, types, balances.

- **`AuditLog`**: Security and action tracking across the platform.
- **`ExchangeRate`**: Currency pairs and timestamped rates.
- **`Tag` & `Category`**: Classification entities.

## Data Flow

1. User logs transaction -> `Transaction` stored in SQLite -> WebSocket event pushed via `ledger_stream`.
2. Analytics trigger -> `ai_alerts` and `subscription_leakage` evaluate monthly records against `FinancialProfile`.
3. Advisor route accessed (`/ai/advisor`) -> compiles live health score, ML spending forecasts, overspending alerts, and alternatives.
4. User asks AI a question -> `GroqMiddleware` resolves active API key -> assembles financial context system prompt -> invokes Groq API -> streams response -> saves to `AiChatMessage`.
5. Export requested -> `pdf_export` or `excel_export` generates structured document on-the-fly.
