## Lessons Learned & Key Decisions
- **In-Memory Dual Exports**: Using ReportLab and OpenPyXL in-memory byte buffers avoids Windows GTK/cairo binary dependencies and cleans up file handles cleanly.
- **WebSocket Streaming vs Polling**: Real-time push at `/ws/ledger` eliminates polling overhead for downstream BI consumers and UI widgets.
- **Multi-Tiered API Fallback**: Providing offline rule-based financial advice when no Groq key is present ensures an uninterrupted user experience.
